# PopUp – Text Adventure in .NET MAUI

An interactive story game made only with pop-up dialogs. The player enters a name, picks a story
(for example a zombie apocalypse or an abandoned school), and makes choices that lead to different endings.

## Features

- Several stories with branching choices and multiple endings
- Built with MAUI dialogs: `DisplayAlert`, `DisplayActionSheet` and `DisplayPromptAsync`
- Available in Estonian, Russian and English

## Tech

C#, .NET 10, .NET MAUI (Android, iOS, Windows, macOS).

## Run

Open `PopUpEE.slnx` in Visual Studio 2022+ with the .NET MAUI workload, choose Android Emulator or Windows Machine, and press Run.
